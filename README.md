*Telco Customer Churn Prediction*
A machine learning project built to predict customer churn in the telecommunications sector. By analyzing customer demographics, account information, and service usage, this model identifies customers at high risk of leaving, enabling proactive retention strategies.
The model is specifically optimized to catch as many potential churners as possible, prioritizing Recall to minimize lost revenue.
Current Performance:
Recall: 80% (Successfully flags 80% of actual churners)
Accuracy: 77% (Overall correct predictions)
Precision: 55% (When flagged as churning, 55% actually churn)
